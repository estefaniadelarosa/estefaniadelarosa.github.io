Multiple Testing.

 
El Multiple Testing se refiere a la situación que surge cuando se realizan múltiples pruebas de hipótesis estadísticas simultáneamente en un mismo conjunto de datos. Realizar muchas pruebas aumenta la probabilidad de encontrar "falsos positivos" (errores de Tipo I) solo por azar. Por ello, es crucial aplicar métodos de corrección de p-valores, como Bonferroni, Holm o Benjamini-Hochberg, para controlar esta tasa de error y asegurar que los descubrimientos sean estadísticamente robustos. En esta sección, exploraremos cómo identificar variables significativas y ajustar los p-valores para mantener la validez de nuestros hallazgos.

Paso 2: Aplicar Análisis de Componentes Principales (PCA).

Por qué: El conjunto de datos de expresión génica tiene una alta dimensionalidad (muchas características). PCA es una técnica de reducción de dimensionalidad que nos permite transformar los datos a un espacio de menor dimensión, manteniendo la mayor parte de la varianza original. Esto es útil para la visualización y para mejorar el rendimiento de los algoritmos de clustering.

Para qué: Reduciremos las más de 6000 características a solo dos componentes principales (PC1 y PC2) para poder visualizarlas fácilmente en un gráfico 2D. También calcularemos la varianza explicada por cada componente para entender cuánta información retienen.

Paso 5: Realizar T-test entre Clúster 1 y Clúster 2 y Análisis de Variables Significativas.

Por qué: Para identificar qué genes (variables) muestran diferencias significativas en su expresión entre los dos clústeres. Esto puede revelar marcadores biológicos importantes que distinguen a estos grupos. El clustering agrupa por similitud, y un t-test nos ayuda a cuantificar y validar estas diferencias a nivel de cada característica original.

Para qué: Realizaremos pruebas t de Student para cada variable de expresión génica entre los puntos de datos asignados al Clúster 1 y al Clúster 2. Luego, filtraremos las variables que tengan un valor p por debajo de un umbral de significancia (ej. 0.05) para determinar cuáles son estadísticamente diferentes y, por lo tanto, las más relevantes para distinguir estos dos grupos.
In [5]:
from scipy import stats

# Convertir X a DataFrame para facilitar la manipulación y mantener nombres de columnas
X_df = pd.DataFrame(X)

# Añadir las etiquetas de clúster a X_df
X_df['Cluster'] = pca_df['Cluster']

# Filtrar los datos para el Clúster 1 y el Clúster 2
cluster1_data = X_df[X_df['Cluster'] == 1].drop(columns=['Cluster'])
cluster2_data = X_df[X_df['Cluster'] == 2].drop(columns=['Cluster'])

# Lista para almacenar variables significativas
significant_variables = []
p_value_threshold = 0.05 # Nivel de significancia

# Realizar t-tests para cada variable (gen)
# Iteramos sobre las columnas del DataFrame original de genes (sin la columna 'Cluster')
for col_idx in range(X_df.shape[1] - 1): # Excluyendo la última columna 'Cluster'
    # Asegurarse de que ambos clústeres tengan suficientes muestras para el t-test
    if len(cluster1_data) > 1 and len(cluster2_data) > 1:
        stat, p_value = stats.ttest_ind(cluster1_data.iloc[:, col_idx], cluster2_data.iloc[:, col_idx], equal_var=False) # Welch's t-test
        if p_value < p_value_threshold:
            # Si X_df tiene nombres de columnas, usarlos, de lo contrario, el índice
            variable_name = X_df.columns[col_idx]
            significant_variables.append((variable_name, p_value))

print(f"Número de variables significativas (p < {p_value_threshold}): {len(significant_variables)}")

if significant_variables:
    # Ordenar las variables significativas por p-valor (de menor a mayor)
    significant_variables.sort(key=lambda x: x[1])
    print("\nPrimeras 10 variables significativas (y sus p-valores):")
    for var_name, p_val in significant_variables[:10]:
        print(f"  Variable {var_name}: p-valor = {p_val:.4f}")

Comparativa y Contexto de los Métodos de Ajuste de p-valores.

Entender las diferencias entre Bonferroni, Holm y Benjamini-Hochberg es crucial para interpretar correctamente los resultados de análisis con múltiples comparaciones. Cada método ofrece un enfoque distinto para controlar el error Tipo I, adecuado para diferentes escenarios y tolerancias al riesgo.

1. Corrección de Bonferroni.

¿Qué hace? Es el método más simple y conservador. Ajusta el nivel de significancia dividiendo el alpha original (ej. 0.05) por el número total de pruebas. Esto significa que cada p-valor individual debe ser muy pequeño* para ser considerado significativo.
* Controla: La Tasa de Error Tipo I (Family-Wise Error Rate - FWER), garantizando que la probabilidad de cometer al menos un falso positivo en todo el conjunto de pruebas sea menor o igual a alpha.
* Características: Altamente conservador, ideal cuando es crítico evitar cualquier falso positivo. Sin embargo, tiene una baja potencia, lo que significa que es propenso a cometer falsos negativos (no detectar efectos reales).
* Resultado en este análisis: Identificó el menor número de variables significativas (334), reflejando su estricto criterio.

2. Método de Holm (Holm-Bonferroni).

* ¿Qué hace? Es una mejora del método de Bonferroni, menos conservador pero igual de estricto en el control del FWER. Ajusta los p-valores de manera secuencial, ordenándolos y aplicando un ajuste escalonado.
* Controla: También el FWER, pero con una mayor potencia que Bonferroni.
* Características: Ofrece un mejor equilibrio entre el control del error Tipo I y la potencia estadística. Es preferible a Bonferroni en la mayoría de los casos donde se busca controlar el FWER.
* Resultado en este análisis: Identificó 345 variables significativas, un número ligeramente superior a Bonferroni, demostrando su mayor potencia sin sacrificar el control de la Tasa de Error Tipo I.

3. Método de Benjamini-Hochberg (FDR).

* ¿Qué hace? Es fundamentalmente diferente, ya que no controla el FWER, sino la Tasa de Descubrimiento Falso (False Discovery Rate - FDR). La FDR es la proporción esperada de falsos positivos entre todas las hipótesis que se declaran significativas. Con un FDR del 1%, se espera que, en promedio, no más del 1% de los resultados significativos sean falsos positivos.
* Controla: La FDR.
* Características: Mucho menos conservador y más potente que Bonferroni y Holm. Es ideal para análisis con un gran número de pruebas (como el análisis de expresión génica), donde se espera que haya muchos resultados verdaderamente significativos y se prefiere un equilibrio entre la detección de verdaderos positivos y el control de falsos descubrimientos.
* Resultado en este análisis: Con un FDR del 1%, identificó 1386 variables significativas, un número considerablemente mayor que los otros dos métodos. Esto es típico de BH, permitiendo más descubrimientos con un riesgo controlado.
 
Conclusión.

La elección del método de ajuste de p-valores debe basarse en el contexto de la investigación y en la pregunta específica que se intenta responder:

* Si la prioridad absoluta es evitar cualquier falso positivo (controlar el FWER de forma estricta), Bonferroni o Holm son adecuados, siendo Holm la opción más potente.
* Si se trabaja con grandes volúmenes de datos y se busca maximizar los descubrimientos sin que una proporción controlada de falsos positivos sea un problema, el método de Benjamini-Hochberg (FDR) es la mejor opción, ya que ofrece una mayor potencia y permite identificar un mayor número de resultados potencialmente relevantes.

Preparación para Q-Learning: Discretización de Estados y Parámetros.

Para aplicar Q-Learning al entorno CartPole-v1, necesitamos discretizar el espacio de observación continuo en un número finito de estados. Esto se logra dividiendo el rango de cada característica de observación en 'bins' o segmentos.

# 1. Definición de límites y bins para la discretización del estado
# Posición del carro: -2.4 a 2.4 (de Gymnasium)
# Velocidad del carro: -0.5 a 0.5 (límite razonable, Gymnasium usa inf)
# Ángulo del palo: -0.2095 a 0.2095 radianes (12 grados, de Gymnasium)
# Velocidad angular del palo: -2 a 2 (límite razonable, Gymnasium usa inf)

state_boundaries = [
    # Cart Position: [-2.4, 2.4]
    [-2.4, 2.4],
    # Cart Velocity: [-0.5, 0.5] (ajustado para ser más manejable, el valor teórico es -inf, inf)
    [-0.5, 0.5],
    # Pole Angle: [-0.2095, 0.2095] radianes
    [-0.2, 0.2],
    # Pole Angular Velocity: [-2, 2] (ajustado para ser más manejable, el valor teórico es -inf, inf)
    [-2.0, 2.0]
]

# Cantidad de bins por cada característica (mayor bins = mayor precisión, más lento)
# El usuario sugirió (1,1,6,12) como punto de partida, pero eso no discretizaría bien las dos primeras.
# Se ajusta para que todas las dimensiones tengan bins significativos para el Q-Learning.
# Se usará la sugerencia del usuario como una base para el número de bins.
num_bins = [1, 1, 6, 12] # Esto es solo un punto de partida, puede ser ajustado

# La discretización requiere que al menos haya 2 bins para cada dimensión para tener algún efecto.
# Si '1' bin se refiere a no discretizar o usar todo el rango como un único bin.
# Ajustaremos a un mínimo de 3 bins para las dimensiones que se sugirieron con 1 para que tenga sentido.
num_bins_adjusted = []
for i, num_b in enumerate(num_bins):
    if num_b == 1 and i < 2: # Para las dos primeras dimensiones si se sugiere 1 bin
        num_bins_adjusted.append(10) # Usar un valor razonable como 10 bins
    else:
        num_bins_adjusted.append(num_b)

print(f"Límites de los estados: {state_boundaries}")
print(f"Número de bins por dimensión (ajustado): {num_bins_adjusted}")

# 2. Función para discretizar el estado
def discretize_state(observation):
    discrete_state = []
    for i in range(len(observation)):
        feature = observation[i]
        min_val, max_val = state_boundaries[i]
        bins = num_bins_adjusted[i]

        # Clamp the feature value to be within the defined boundaries
        feature = max(min_val, min(feature, max_val))

        # Calculate the bin index
        bin_index = int(((feature - min_val) / (max_val - min_val)) * bins)

        # Ensure bin_index is within valid range [0, bins-1]
        discrete_state.append(min(bins - 1, max(0, bin_index)))
    return tuple(discrete_state)

import random
import numpy as np
import matplotlib.pyplot as plt

# Lista para almacenar las recompensas de cada episodio
rewards_per_episode = []

# Bucle principal de entrenamiento
print(f"Iniciando entrenamiento Q-Learning para {num_episodes_ql} episodios...")

for episode in range(num_episodes_ql):
    # Reiniciar el ambiente y obtener el estado inicial
    observation, info = env.reset()
    current_state = discretize_state(observation)
    current_episode_reward = 0
    terminated = False
    truncated = False

    for step in range(max_steps_per_episode):
        # Estrategia epsilon-greedy para la selección de acciones
        if random.uniform(0, 1) < exploration_rate:
            action = env.action_space.sample() # Exploración: acción aleatoria
        else:
            action = np.argmax(q_table[current_state]) # Explotación: mejor acción de la Q-table

        # Realizar la acción en el ambiente
        new_observation, reward, terminated, truncated, info = env.step(action)
        new_state = discretize_state(new_observation)

        # Acumular recompensa
        current_episode_reward += reward

        # Actualización de la Q-table (fórmula de Bellman)
        # Q(s,a) = Q(s,a) + alpha * [reward + gamma * max(Q(s',a')) - Q(s,a)]
        max_future_q = np.max(q_table[new_state]) # Valor Q máximo del nuevo estado
        current_q = q_table[current_state + (action,)] # Valor Q actual del estado-acción

        new_q = current_q + learning_rate * (reward + discount_factor * max_future_q - current_q)
        q_table[current_state + (action,)] = new_q

        # Actualizar el estado actual
        current_state = new_state

        # Si el episodio termina (palo cae o límite de tiempo), salir del bucle de pasos
        if terminated or truncated:
            break

    # Decaimiento de la tasa de exploración (epsilon)
    exploration_rate = max(min_exploration_rate, exploration_rate * exploration_decay_rate)

    # Almacenar la recompensa total del episodio
    rewards_per_episode.append(current_episode_reward)

    # Imprimir progreso
    if (episode + 1) % 500 == 0:
        print(f"Episodio {episode + 1}/{num_episodes_ql} - Recompensa: {current_episode_reward:.2f} - Epsilon: {exploration_rate:.4f}")
